# 지구 지킴이 뉴스룸 (교사용 안내)

초등학교 4학년 과학 「생물과 환경」 중 *"인간 활동이 생태계에 어떤 영향을 미칠까요?"* 차시를 위한 개인 활동용 웹앱입니다. (학생 1명당 태블릿 또는 PC 1대)
학생들은 환경오염 사례를 스크랩하고, 뉴스 기사를 쓰고, 캔바로 발표자료를 만든 뒤 퀴즈에 도전합니다.

- 서버·로그인·설치가 필요 없습니다. `index.html`을 열면 바로 실행됩니다.
- 학습 기록은 그 기기의 브라우저(localStorage)에만 저장됩니다. 밖으로 전송되지 않습니다.
- 태블릿(가로·세로)과 PC 화면 모두에서 동작합니다.

## 파일 구성

```
index.html      화면 뼈대
css/style.css   디자인 (폰트, 색, 반응형)
js/app.js       앱 동작 (보통은 손대지 않아도 됩니다)
js/config.js    ★ 교사 설정 (캔바 링크, 스크랩 조건, 퀴즈 문항 수 등)
data/cases.js   ★ 사례 데이터 (사례 내용, 사진, 출처 링크, 직접 만든 퀴즈)
README.md       이 안내문
```

★ 표시된 두 파일만 바꾸면 수업에 맞게 고칠 수 있습니다. 메모장이나 VS Code로 열어 수정하세요.
**파일은 반드시 UTF-8 인코딩으로 저장**해야 한글이 깨지지 않습니다.

## 1. 사례·링크·사진 바꾸기 (`data/cases.js`)

사례 하나는 아래 모양입니다.

```js
{
  id: "water-01",            // 겹치지 않는 고유 이름 (바꾸면 학생 기록과 연결이 끊깁니다)
  type: "water",             // "air"(대기) | "water"(수질) | "soil"(토양)
  title: "비닐을 해파리로 착각한 바다거북",
  body: "4학년 수준 설명 3~4문장 …",
  activity: "사람의 활동 한 줄",
  pollution: "어떤 오염이 생겼는지 한 줄",
  effect: "생물·생태계에 생긴 일 한 줄",
  imageUrl: "",              // 사진 주소. 비우면 종류별 그림(이모지)으로 표시
  sourceUrl: "",             // 실제 기사 링크
  sourceName: "",            // 자료 이름 (예: ○○신문, 환경부 누리집)
  quiz: [ … ]                // (선택) 직접 만든 퀴즈 문항
}
```

- **사례 추가**: 배열 안에 같은 모양의 항목을 하나 더 넣습니다. 종류별 5개 이상을 권장합니다(퀴즈 보기 생성에 넉넉합니다).
- **사례 삭제**: 해당 `{ … },` 블록을 지웁니다.
- **사진 넣기**: `imageUrl`에 사용 허가된 사진 주소를 넣습니다. 앱 폴더 안에 `img/` 폴더를 만들고 `imageUrl: "img/turtle.jpg"`처럼 상대 경로를 써도 됩니다.
- **출처 넣기**: `sourceUrl`에 기사 링크, `sourceName`에 자료 이름을 넣으면 카드 아래에 링크가 표시됩니다.
- 기본 사례는 모두 이 앱을 위해 새로 쓴 **학습용 사례**이며 카드에 "학습용 사례"라고 표시됩니다. 실제 언론사·기자·날짜·장소·수치는 넣지 않았습니다.

### 직접 퀴즈 문항 만들기 (`quiz` 필드)

사례마다 문항을 넣어 둘 수 있습니다. 넣지 않아도 사례 내용에서 자동으로 문항이 만들어집니다.

```js
quiz: [
  { type: "ox", question: "플라스틱을 태우면 공기가 깨끗해진다.", answer: false, explain: "해로운 연기가 나와요." },
  { type: "choice", question: "다 쓴 건전지는 어떻게 버릴까요?",
    options: ["일반 쓰레기", "땅에 묻기", "수거함에 따로", "물에 버리기"], answer: 2, explain: "…" },
  { type: "initial", question: "아주 작게 부서진 플라스틱은?", answer: "미세 플라스틱", explain: "…" }
]
```

- `choice`의 `answer`는 정답 번호이며 **0부터** 셉니다.
- `initial`(초성 퀴즈)은 `answer`의 초성(예: ㅁㅅ ㅍㄹㅅㅌ)을 자동으로 보여 줍니다.

## 2. 교사 설정 바꾸기 (`js/config.js`)

| 항목 | 뜻 | 기본값 |
|---|---|---|
| `canvaUrl` | "캔바 열기" 버튼이 여는 주소 | `https://www.canva.com` |
| `scrapRule.minPerType` | 종류별 최소 스크랩 수 | 1 |
| `scrapRule.minTotal` | 전체 최소 스크랩 수 | 3 |
| `quiz.count` | 퀴즈 문제 수 | 10 |
| `quiz.retryWrong` | 틀린 문제 다시 풀기 | true |
| `quiz.mix` | 유형별 문항 수 (type / effect / chain / ox / initial) | 5 / 2 / 1 / 1 / 1 |
| `badges` | 배지 기준(정답률 %)과 이름 | 90 / 70 / 0 |

### 캔바 학급 템플릿 링크 넣기

1. 캔바에서 학급용 템플릿을 만들고 **공유 → 템플릿 링크** (또는 과제 링크)를 복사합니다.
2. `js/config.js`에서 아래 줄을 바꿉니다.
   ```js
   canvaUrl: "https://www.canva.com/design/XXXXXXXX/edit",
   ```
3. 저장한 뒤 브라우저를 새로고침하면 "캔바 열기" 버튼이 그 링크로 열립니다.

## 3. 학생에게 배포하기

**방법 A. 폴더 그대로 전달 (가장 간단)**
폴더 전체(`index.html`, `css`, `js`, `data`)를 USB나 학급 공유 드라이브로 전달하고, 태블릿에서 `index.html`을 엽니다.
※ 폰트는 눈누(noonnu.cc) 웹폰트를 인터넷에서 불러옵니다. 인터넷이 없으면 기기의 기본 글꼴로 표시되며 동작에는 문제가 없습니다.

**방법 B. 무료 정적 호스팅에 올리기 (권장)**
GitHub Pages, Netlify Drop, Google 사이트 도구 등에 폴더를 올리고 주소나 QR 코드를 학생에게 나누어 줍니다.
- Netlify Drop: <https://app.netlify.com/drop> 에 폴더를 끌어다 놓으면 바로 주소가 생깁니다.
- 클립보드 복사("글 복사" 버튼)는 `https://` 주소 또는 로컬 파일에서 동작합니다.

**수업 전 점검**
- 학생마다 기기 1대, 같은 기기로 계속 진행합니다(기록이 기기에 저장되기 때문입니다).
- 이전 학생의 기록이 남아 있으면 화면 아래 **"처음부터 다시"** 버튼으로 지웁니다.
- 캔바에 로그인되어 있는지 확인합니다.
